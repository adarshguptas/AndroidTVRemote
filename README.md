# Android TV Remote

An Android application designed to control Android TV devices through a simple and user-friendly interface.

## Features
- Easy-to-use remote control interface
- Convenient TV navigation
- Android TV connectivity
- Simple and intuitive design

## Technologies
- Android SDK
- Kotlin / Java

## Installation
1. Clone this repository.
2. Open the project in Android Studio.
3. Sync Gradle dependencies.
4. Build and run the application.
