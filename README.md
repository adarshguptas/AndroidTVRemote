# Android TV Remote

An Android application designed to control Android TV devices with a simple and intuitive mobile interface.

## Overview

Android TV Remote provides convenient TV navigation, device discovery, secure pairing, and voice-based command support.

## Features

- Android TV device discovery
- Secure device pairing and communication
- Remote navigation and control
- Voice recognition and command processing
- Modern Android user interface
- Theme preferences and local data storage

## Tech Stack

- Kotlin
- Android SDK
- Jetpack Compose
- Material 3
- Kotlin Coroutines
- Gradle

## Requirements

- Android Studio
- JDK 17
- Android device running Android 9.0 or later
- Compatible Android TV device and network connection

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/adarshguptas/AndroidTVRemote.git
   ```

2. Open the project in Android Studio.

3. Allow Gradle to sync and download the required dependencies.

4. Connect your Android device or start an emulator.

5. Build and run the application.
